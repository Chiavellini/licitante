# licitante.mx

Licitaciones públicas abiertas en México y Colombia — sólo procedimientos competidos.

Generado desde datos abiertos: ComprasMX (Secretaría Anticorrupción y Buen Gobierno) y
SECOP II (Colombia Compra Eficiente). Se regenera semanalmente.

Este repositorio contiene únicamente la página publicada. No contiene datos de contacto.
